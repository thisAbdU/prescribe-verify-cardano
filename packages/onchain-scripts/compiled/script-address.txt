Nothing to do!  Available modes of operation are:

Scripts mode:
  * Set the NETWORK env var to a valid cardano network, such as mainnet to use default network config.

Custom mode:
  * Leave the NETWORK env var unset and provide entrypoint args starting with "run" and:
    * Optionally set environment variables interpreted by /usr/local/bin/run-node.
    * Optionally include additional cardano-node args to the entrypoint after "run".

Merge mode:
  * Set the NETWORK env var to a valid cardano network, such as mainnet, and
    set CARDANO_CONFIG_JSON_MERGE and/or CARDANO_TOPOLOGY_JSON_MERGE env vars
    with valid json to run cardano-node with deep merged base NETWORK and custom config.
  * The extra environment variables and cardano-node args that can be used in custom mode
    are also available in merge mode.

CLI mode:
  * Leave the NETWORK env var unset and provide entrypoint args
    starting with "cli" followed by cardano-cli command args.
  * A docker volume mount to the cardano-node ipc socket will need to be included, example:
      -v node-ipc:/ipc
